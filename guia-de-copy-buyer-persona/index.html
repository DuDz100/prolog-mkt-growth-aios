Jornada de Compra — Mensagem Certa, Momento Certo

Cada persona tem um papel em cada etapa. Saber disso evita enviar a mensagem errada na hora errada.

Estágio 1
Consciência do Problema
👑 Champion — sente a dor 🗣️ Influenciador — percebe risco 🖊️ Decisor — ainda fora 🚫 Blocker — ainda fora
Estágio 2
Busca de Solução
👑 Champion — busca ferramenta 🗣️ Influenciador — estrutura o problema 🖊️ Decisor — percebe o custo 🚫 Blocker — ainda fora
Estágio 3
Avaliação
🗣️ Influenciador — qualifica e apresenta 👑 Champion — valida na prática 🚫 Blocker — levanta objeções 🖊️ Decisor — pergunta sobre ROI
Estágio 4
Decisão
🚫 Blocker — libera (ou veta) 🖊️ Decisor — assina 👑 Champion — implanta 🗣️ Influenciador — garante aderência
Estágio 5
Pós-venda / Expansão
👑 Champion — termômetro 🗣️ Influenciador — indicações 🖊️ Decisor — avalia renovação 🚫 Blocker — verifica entrega
Regras de Ouro para Agentes de Copy
Regra 1
Identifique a persona antes de escrever — uma palavra errada no headline desqualifica tudo.
Regra 2
Prova social adequada à persona: Decisor quer ROI; Champion quer depoimento de par; Influenciador quer case similar; Blocker quer documentação.
Regra 3
CTA revela a persona: "Veja o case" ≠ "Teste agora" ≠ "Consulte arquitetura" — cada um fala um idioma diferente.
Regra 4
Blocker é o gargalo — se a copy não passa no filtro dele, nada avança. Nunca ignore-o.
Regra 5
Champion é o amplificador — se ele abraça, o boca a boca é orgânico e poderoso.
Regra 6
Influenciador é a porta de entrada — copy dele precisa ser "confiável, não entusiasmada".
Regra 7
Uma campanha completa atinge os 4 — cada peça para uma persona, não uma peça genérica para todos.
Regra 8
Blocker convencido vira aliado poderoso. "Até o Marcos aprovou" é mais convincente que qualquer promessa comercial.
Checklist — Antes de Publicar Qualquer Copy

Identificação & Linguagem

  • Sei para qual persona estou escrevendo?
  • A copy foi pensada para essa persona específica?
  • Estou na mídia certa para atingir essa persona?
  • Em qual estágio da jornada ela está?
  • Uso pelo menos 1 palavra-gatilho da persona?
  • Evitei os termos bloqueadores?
  • O tom está correto?

Persuasão & Dinâmica

  • A copy ativa o botão de decisão da persona?
  • Há pelo menos 1 prova adequada ao perfil?
  • Se houver objeção óbvia, ela é antecipada?
  • O CTA é adequado para a persona e o estágio?
  • Se para Decisor: tem algo que o Influenciador possa levar a ele?
  • Se para Champion: tem depoimento de par?
  • Se para Blocker: tem documentação técnica disponível?

Use pelo menos UMA das palavras-gatilho da persona 2. Evite todos os termos bloqueadores da persona 3. Inclua o CTA adequado: Decisor → "Veja o case"; Champion → "Teste agora"; Influenciador → "Veja como funciona"; Blocker → "Consulte arquitetura" 4. Tom: Decisor = profissional/dados | Champion = direto/prático | Influenciador = pragmático/técnico | Blocker = cauteloso/estruturado 5. NÃO use: "revolucionário", "disruptivo", "solução completa", "transformação total", "inovador" 6. A copy deve passar no teste: "essa persona específica reconheceria o problema descrito?" ## OUTPUT ESPERADO Entregue: 1. A peça de copy pronta para uso 2. Uma linha explicando qual gatilho principal foi usado 3. Uma sugestão de A/B test (versão alternativa do headline)
